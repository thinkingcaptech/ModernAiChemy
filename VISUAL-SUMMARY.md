## 🔐 Security Model

```
USER FLOW & SECURITY GATES:

User
  ↓
Visits Landing ................... No restrictions
  ↓
Clicks "Buy Now" ................. No restrictions
  ↓
Stripe Checkout .................. PCI handled by Stripe
  ↓
Payment Confirmed ................ Webhook updates DB
  ↓ DB SET: hasLifetimeAccess = true
  ↓
Sign In/Login .................... ✅ Firebase Auth
  ↓
Dashboard Load ................... ✅ Payment Check (Firestore)
  ↓ If paid: Show tools | If unpaid: Show "Access Denied"
  ↓
Access Tool ...................... ✅ Payment Gate (Firestore Rule)
  ↓
Add API Key ....................... 🔑 Encrypted, Private Storage
  ↓ /users/{uid}/private/api_keys
  ↓
Use Tool ......................... 🔐 Key used client-side only
  ↓
AI API ........................... Direct from user's browser
```
